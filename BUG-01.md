## New — BUG-01
**Summary:** Пошкоджений JSON у localStorage блокує CRUD товарів.

**Environment:** Windows 10.0.26200; Google Chrome 156.0.8078.81; http://127.0.0.1:4173; build 1.0.0; варіант 2.

**Preconditions:** Запущено `npm start`, відкрита сторінка модуля.

**Steps:**
1. У консолі браузера виконати `localStorage.setItem('products-lab34-v2', '{')`.
2. Перезавантажити сторінку.
3. Ввести ID 1, назву Зошит, ціну 25.50, дату 2026-11-07; натиснути Додати.

**Actual:** Товар не додається, лічильник 0; необроблений SyntaxError під час JSON.parse. Обробник форми не підключається.

**Expected:** Показати попередження про пошкоджені дані, зберегти їх резервну копію та дозволити працювати з порожнім списком.

**Severity:** Major — заблоковано весь CRUD у профілі з пошкодженими даними.

**Priority:** Medium — потрібен нетиповий стан локального сховища; нормальний сценарій працює.

**Evidence:** TC15 FAIL; журнал `evidence/initial-results.json`, скриншот `evidence/initial-storage.png` у матеріалах лабораторної.

Виявлено дослідницьким тестом початкової реалізації; дефект не додавався навмисно.

## Локальне виправлення та перевірка

У v1.0.1 читання JSON охоплено try/catch, перевіряється структура масиву. Пошкоджене значення зберігається під ключем products-lab34-v2-backup, основний ключ видаляється, користувач отримує попередження.

Retest TC15: PASS; резервна копія дорівнює початковому пошкодженому значенню, після перезавантаження можна додати товар, необроблених помилок немає. Регресія TC01–TC14: 14 PASS. Докази: fixed-results.json, fixed-warning.png, fixed-storage.png, test-summary.png.
