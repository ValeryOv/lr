# Лабораторна робота №3–4 — варіант 2

CRUD товарів: ID, Name, Price, Special, Date Added. Сортування: ID і Special в обох напрямках.

## Запуск

Потрібен Node.js. У папці проєкту виконайте:

```text
npm install
npm start
```

Відкрийте http://127.0.0.1:4173. Дані зберігаються в localStorage окремо для кожного браузера. Це локальна навчальна панель без авторизації.

## Перевірка

Залиште сервер запущеним та в іншому терміналі виконайте:

```text
npm test -- --fixed
```

Автотести використовують Google Chrome для Windows за стандартним шляхом. Результати та скриншоти зберігаються в `evidence/`. Перед повторним прогоном бажано скопіювати ці матеріали, щоб зберегти попередні результати.

## Дефект BUG-01

Початкова версія `app.v1.0.0.js` не обробляла пошкоджений JSON у localStorage. Виявлено фактично: 14 PASS, 1 FAIL. У v1.0.1 додано перевірку структури, резервну копію й відновлення порожнього списку. Retest та регресія: 15 PASS.

Для відтворення початкової версії зробіть копію папки, замініть `app.js` вмістом `app.v1.0.0.js`, змініть напис версії в index.html на v1.0.0 і виконайте `node test.cjs`.

Звіт про дефект: `BUG-01.md`. Початкові журнали містять реальну необроблену помилку JSON.parse.
